# BusRoute — Online Bus Ticket Reservation Platform

BusRoute is an intercity bus ticket reservation web application built with Python, Django, SQLite, and vanilla HTML/CSS/JavaScript.

## Features
- **Search Buses:** Search available buses by source, destination, and travel date.
- **Compare Options:** Filter and sort buses by departure time, fare, and duration.
- **Interactive Seat Selection:** Luxury 2x2 cabin seat map with real-time fare calculation.
- **User Authentication:** Login, registration, and personal booking history.
- **Admin Dashboard:** Full Django admin portal to add, edit, or delete buses and view reservations.

## Running the Project
1. Run the development server:
   ```bash
   python manage.py runserver
   ```
2. Open your browser:
   - **Website:** `http://127.0.0.1:8000/`
   - **Admin Portal:** `http://127.0.0.1:8000/admin/`
